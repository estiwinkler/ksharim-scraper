# קשרים בריבוע - מאגר יומי אוטומטי 🔤

סורק אוטומטי שרץ כל יום בענן ושומר את חידות היום.

## קבצי הפלט (בתיקיית `data/`)
| קובץ | תוכן |
|------|-------|
| `puzzles_database.json` | מאגר מלא בפורמט JSON |
| `puzzles_database.xlsx` | טבלה מעוצבת ב-Excel |
| `scrape_log.txt` | לוג כל הסריקות |

## הרצה ידנית
GitHub → Actions → "קשרים בריבוע - סריקה יומית" → Run workflow
